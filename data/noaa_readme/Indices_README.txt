               WAREHOUSE of Historical SWPC Products

The SWPC warehouse directory (/warehouse) contains historical products
from 1996 up to the current day in yearly sub-directories including the
Solar and Geomagnetic Indices and Solar Event Reports in this directory.
  Via Anonymous FTP ftp.swpc.noaa.gov cd to /pub/warehouse
  Via the Web   http://www.swpc.noaa.gov/ftpdir/warehouse


Space Weather Indices and Events are archived at the National Geophysical
Data Center. See http://www.ngdc.noaa.gov/stp/

Notices of data changes http://www.swpc.noaa.gov/Data/about_data.html and
http://www.swpc.noaa.gov/Data/notices.html

               Thule Neutron Monitor Daily Percent of Background
                             To Be Discontinued

June 1, 2010 SWPC discontinued the Daily Thule "Neutron Monitor Percent of
Background" field in the Daily Particle Data and Daily Space Weather
Indices reports.

The fields will not be removed but will contain -999.9

For more details, alternative sources, and SWPC contact information.
See http://www.swpc.noaa.gov/Thule.html
