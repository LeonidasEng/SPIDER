Determining Predicted Kp value
"What is the most recent forecast issued before DATE 00:00 UT that contains a prediction for this bin?"

Using OMNI2 data
DO NOT average 1-hour values to 3-hour bins. Instead, select the “latest available” hour per 3-hour bin.
    "Operators react to current conditions, not means."

Feature Engineering

    METADATA describes how records are identified, aligned and traced in time, but not used by model.

    LABELs describe the observed ground-truth state of the system

    DERIVED LABELs describe ground-truth outcomes computed from labels using defined evaluation rules

    FEATUREs describe the forecast context and upstream physics

    TARGETs describe what actually happened

    OUTPUTs describe what the system believes will happen

    PARAMETERs define how success or failure is measured

    Index Metadata
        issue_time_utc                                                                  [METADATA]          Tier 1          Required for lead-time computation                                                 
        valid_start_utc (start of 3-hour bin)                                           [METADATA]          Tier 1          Required for bin alignment
        valid_end_utc                                                                   [METADATA]          Tier 1          Required for bin definition (Redundant)
        kp_bin                                                                          [METADATA]          Tier 1          Readable bin ID (Redundant)
    
    Forecast Features
        lead_hours (derived)                                                            [FEATURE]           Tier 1          Preferred over calendar-based lead             
        lead_days (derived)                                                             [FEATURE]           Tier 2          Optional Categorical alternative

        kp_pred                         = Predicted Kp                                  [FEATURE]           Tier 1          Core forecast
        kp_pred_trend                   = rising/falling across bins                    [FEATURE]           Tier 2          Useful for regime awareness 
        kp_predicted_max_day            = MAX(kp_pred) (optional)                       [FEATURE]           Tier 3          Risk of temporal leakage 

    Observed
        kp_obs                          = Estimated SWPC Kp (ground-truth)              [LABEL]             Tier 1          Ground Truth only                 

    Derived    
        delta_kp                        = kp_obs - kp_pred (ground-truth)               [LABEL]             Tier 1          Core verification quantity

    Targets (Training)
        abs_delta_kp                    = |delta_kp| Regression (ground-truth)          [TARGET]            Tier 2          Harder to explain operationally      
        
        is_large_error                  = 1 if |ΔKp| ≥ 1 else 0 (Probabilistic)         [TARGET]            Tier 1          Primary Reliability Target
        is_very_bad_miss                = 1 if |ΔKp| ≥ 2 else 0 (Probabilistic)         [TARGET]            Tier 1          Safing relevant escalation
        is_ok                           = 1 if |ΔKp| < 1 else 0                         [TARGET]            -               Redundant (1 - is_large_error)    

    Windowed Targets (MVP-friendly) (optional) 
        error_tolerance_bins        = ±1 bin (±3 hours) or ±2 bins (±6 hours)           [PARAMETER]         Tier 2          Introduced with timing sensitivity
        
        abs_delta_kp_win(t)         = min over τ in [t−w, t+w]                          [DERIVED LABEL]     Tier 2          Supports Owens-style verification 
                                      of |kp_obs(τ) − kp_pred(t)|      
        
        is_large_error_win          = 1 if abs_delta_kp_win ≥ 1 else 0 (Probabilistic)  [TARGET]            Tier 2          Timing-aware Reliability
        is_very_bad_miss            = 1 if abs_delta_kp_win ≥ 2 else 0 (Probabilistic)  [TARGET]            Tier 2          Timing-aware Safing
    
    Event-based Targets (Storm-Centric) (optional)
        storm_threshold_kp          = 5.0                                           [PARAMETER]             Tier 3          Mission-specific
        event_window_bins           = ±2 bins (±6 hours)                            [PARAMETER]             Tier 3          Event Tolerance
        
        storm_event_occurred        = 1 if any kp_obs ≥ storm_threshold_kp          [DERIVED LABEL]         Tier 3          Event Detection
                                        occurs within ±6h of forecasted peak
                                        else 0
        is_missed_storm_event       = 1 if storm_event_occurred = 1 and             [TARGET]                Tier 3          Event Reliability
                                        kp_pred_peak < storm_threshold_kp
                                        else 0
        is_false_storm_alarm        = 1 if kp_pred_peak ≥ storm_threshold_kp        [TARGET]                Tier 3          Over-warning analysis
                                        AND no kp_obs ≥ storm_threshold_kp
                                        else 0

    OMNI2 features

        Solar wind & IMF (OMNI) parameters
            bz_gsm                      = Southward IMF vector (GSM)                    [FEATURE]           Tier 1          Dominant coupling driver
            b_mag                       = Magnitude of IMF                              [FEATURE]           Tier 1          Field strength context
            v_sw                        = Solar Wind Speed                              [FEATURE]           Tier 1          Solar wind driving
            np_sw                       = Proton density                                [FEATURE]           Tier 1          Density / Pressure
            pdyn                        = Dynamic Pressure                              [FEATURE]           Tier 1          Magnetopause compression

        Coupling Proxies
            Ey                          = Solar Wind Electric Field (-V*Bz)             [DERIVED FEATURE]   Tier 1          Compact coupling metric
            plasma_beta                 = Magnetic vs Thermal dominance                 [DERIVED FEATURE]   Tier 1          Regime indicator
            mach_alfven                 = Alfvén Mach number                            [DERIVED FEATURE]   Tier 1          Shock / compressibility
            VBs                         = Effective driving V*max(0, -Bz)               [DERIVED FEATURE]   Tier 2          Alternative coupling form

        Context
            f107                        = F10.7 solar Radio Flux (long-term)            [FEATURE]           Tier 1          Solar cycle context
            sunspot_no                  = Sunspot number                                [FEATURE]           Tier 2          Correlated with F10.7
            Lagged Dst or AE            = Disturbance Storm-Time or Auroral Electrojet  [FEATURE]           Tier 3          Risk of response leakage

        Temporal Persistence
            bz_mean_3h                  = Rolling mean                                  [FEATURE]           Tier 2          Reduces noise                        
            bz_min_6h                   = Rolling min                                   [FEATURE]           Tier 2          Storm onset sensitivity
            bz_std_3h                   = Rolling Standard Deviation of Bz and V        [FEATURE]           Tier 2          Variability
            southward_duration_h        = Duration of sustained southward Bz            [FEATURE]           Tier 2          Persistence
            pressure_jump_flag          = Pdyn increase over previous hour to 3h        [FEATURE]           Tier 2          CME indicator

    
    Potential Model Outputs

        p_large_error                   = P(is_large_error = 1)                       [MODEL OUTPUT]        Tier 1          Primary Confidence Output
        p_very_bad_miss                 = P(is_very_bad_miss = 1)                     [MODEL OUTPUT]        Tier 1          Safing escalation

        p_large_error_win               = P(is_large_error_win = 1)                   [MODEL OUTPUT]        Tier 2          Timing-aware confidence
        p_very_bad_miss_win             = P(is_very_bad_miss_win = 1)                 [MODEL OUTPUT]        Tier 2          Timing-aware confidence

        
        p_missed_storm_event            = P(is_missed_storm_event = 1)                [MODEL OUTPUT]        Tier 3          Event-level guidance
        p_false_storm_alarm             = P(is_false_storm_alarm = 1)                 [MODEL OUTPUT]        Tier 3          Event-level guidance
